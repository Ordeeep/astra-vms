# Interface do Astra

A interface usa shadcn/ui, tema escuro, cores ciano e fonte Inter. Os componentes compartilhados ficam em src/components/ui; os estilos gerais em src/app.

O login usa o Topography do React Bits como fundo decorativo. O gradiente CSS aparece enquanto o efeito carrega, quando WebGL 2 está indisponível ou quando o usuário prefere movimento reduzido. A exportação pública usa a cena CSS original OrbitalDawn.

A marca e os ícones usam os ativos Astra presentes em public/brand e src/app. A interface consulta a API na mesma origem HTTPS e respeita as permissões por tenant.
