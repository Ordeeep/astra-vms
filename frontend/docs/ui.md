# Interface do Astra

O [guia de design](../../docs/desing.md) é a referência visual da interface. Os componentes shadcn/ui compartilhados ficam em `src/components/ui` e os tokens de tema em `src/app/globals.css`.

A marca e os ícones usam os ativos Astra presentes em public/brand e src/app. A interface consulta a API na mesma origem HTTPS e respeita as permissões por tenant.
