# Rótulos de triagem

| Papel | Valor no tracker | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Precisa de avaliação |
| needs-info | needs-info | Aguarda informações |
| ready-for-agent | ready-for-agent | Pronto para implementação por agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será implementado |

Use o valor correspondente na linha `Status:` da tarefa durante a triagem.
