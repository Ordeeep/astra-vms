# Documentação de domínio

## Leitura antes de explorar o projeto

O projeto usa um único contexto:

- `GLOSSARY.md` na raiz: vocabulário do domínio.
- `docs/adr/`: decisões de arquitetura; ler as pertinentes à tarefa.

Se esses documentos ainda não existirem, continuar normalmente.
Criá-los conforme termos ou decisões forem resolvidos com a skill
domain-modeling.

## Vocabulário

Usar os termos definidos no glossário em tarefas, propostas e testes.
Quando faltar um conceito necessário, registrar a lacuna para
domain-modeling.

## Decisões

Se uma proposta contrariar uma ADR existente, indicar explicitamente
qual decisão seria revista e explicar o motivo.
