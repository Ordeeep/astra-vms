# Backend modular e processos locais de mídia

Na consolidação da investigação (Q43), foi aprovada como direção inicial a separação em dois repositórios de produto, frontend e backend, com backend modular e processos de mídia no mesmo servidor Windows 11. A autorização permanece sob controle do VMS, inclusive para transmissões; processos especializados não implicam uma controller distribuída nem microserviços/repositórios independentes para cada módulo.

Essa forma preserva as regras do domínio no backend e permite validar motores especializados sem acoplar o produto inteiro ao laboratório. A decisão não escolhe MediaMTX, FFmpeg, banco, linguagens/frameworks ou Docker versus execução nativa: essas escolhas continuam sujeitas a seleção e evidência. Não aprova capacidade, desempenho ou segurança ainda não ensaiados.
